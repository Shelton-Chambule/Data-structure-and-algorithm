# Estrutura de Dados e Algoritmos em Java

🌐 **Idiomas:** [English](README.md) | Português

Repositório de estudos criado para acompanhar o curso gratuito **Estrutura de Dados e Algoritmos**, da professora **Loiane Groner** ([loiane.training](https://loiane.training)), com implementações, exercícios e anotações.

## Sobre o curso

Loiane Groner é uma desenvolvedora brasileira com mais de 10 anos de experiência, Microsoft MVP e Google Developer Expert, autora do livro *"Estruturas de Dados e Algoritmos com JavaScript"* e criadora de cursos gratuitos de programação em `loiane.training`. O curso cobre os fundamentos de estrutura de dados e algoritmos aplicados em Java.

## Objetivo

Consolidar os conceitos fundamentais de estrutura de dados e algoritmos, complementando o aprendizado em desenvolvimento backend com Java.

## Tópicos abordados

- [ ] Complexidade de algoritmos (Big O)
- [🔄] Vetores (Arrays) — *em estudo (Aula 05)*
- [ ] Listas Ligadas (simples, duplas, circulares)
- [ ] Pilhas (Stacks)
- [ ] Filas (Queues)
- [ ] Árvores Binárias e Árvores Binárias de Busca
- [ ] Tabelas Hash
- [ ] Grafos
- [ ] Algoritmos de ordenação (Bubble, Insertion, Selection, Quick, Merge Sort)
- [ ] Algoritmos de busca (Linear, Binária)
